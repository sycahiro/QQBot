# QQ 连接

本模块通过独立的 SnowLuma 进程与本机已登录的个人 QQ 交互。

- `discovery.py`：进程发现和账号身份读取。
- `selection.py`：保存用户选中的账号。
- `snowluma.py`、`engine.py`：管理引擎进程和通信。
- `connection.py`：显式连接、身份确认和断开。

检测、选择和连接是不同状态；发现 QQ 不等于已连接。应用启动后不会自动连接账号。关闭应用时只清理自身管理的进程，不关闭用户的 QQ。

SnowLuma 是独立第三方项目，按其自身许可使用。安装和测试方法见[项目首页](../../../../README.md)。
